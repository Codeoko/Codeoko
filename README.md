# Codeoko

### Private live coding school · Ages 7–18 · GCC evenings (GST / AST)

**Engineered for the Few.**

Codeoko is an international private coding school. Tiny live studios — **1 mentor : 4 students** — where children write real Python, ship websites, games, and AI systems a parent can open and understand.

🌐 [www.codeoko.com](https://www.codeoko.com)  
✉️ [admissions@codeoko.com](mailto:admissions@codeoko.com)  
📍 Live online · UAE · KSA · Qatar · Kuwait · worldwide

---

### Programs

| Program | Ages | What they ship |
| --- | --- | --- |
| **[First Code](https://www.codeoko.com/programs/first-code)** | 7–10 | Games, stories, first Python |
| **[App Builders](https://www.codeoko.com/programs/app-builders)** | 11–14 | Python, tests, HTML/CSS/JS, deploy |
| **[AI Engineers](https://www.codeoko.com/programs/ai-engineers)** | 15–18 | Data, models, vision, honest limits |

**Term shape:** 24 live studios · 12 weeks · Friday + Saturday
